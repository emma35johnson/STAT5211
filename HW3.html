There is a relationship between the predictors and the response, reflected by the significant p-values associated with variables in the table summary of the model. More specifically, under the model including all potential explanatory variables for mpg, displacement, weight, year, and origin are statistically significant.

Further, the value of \(R^2\) suggests that approximately 82.15% of the variation observed in mpg is attributed to the explanatory variables within the model. A low \(R^2\) would suggest that the explanatory variables do a poor job in fitting the data of the response variable.

An F-test can be conducted to determine whether this full model, that is, one with explanatory variables, performs better than a reduced model with a simple (average) coefficient term describing mpg. The following are test results:

Here are some further testing measures to point out potential outliers and leveraged data points:

n <- nrow(auto)      # sample size
p <- ncol(auto) - 1  # number of predictor variables in model 1

# Finding outliers:
stud.res.test <- function(model, alpha) {
  unique(which(
  abs(rstudent(model)) >= qt(1-alpha/2, n - p - 2)
))
}
stud.res.test(mod1, 0.05)  # all flagged points at alpha level = 0.05
##  [1]  44 108 111 154 165 243 246 269 308 321 323 324 325 326 328 332 382 389
# Bonferroni method:
stud.res.test(mod1, 0.05/(2*n))  # no flagged outliers using Bonferroni adjustment
## integer(0)

Under a less conservative significance level, there are 18 points flagged as potential outliers, whereas using the more conservative Bonferroni adjustment, there are none.

# Finding leverage / influential points:
leverage <- function(model){
  unique(which(
    hatvalues(model) > 2*(p+1)/n
  ))
}
lev.vals <- leverage(mod1)
lev.vals   # flagged leverage values
##  [1]   7   8   9  14  26  27  28  29  95 116 298 299 360 389
# Plotting the results:
color.vec <- rep("black", length(hatvalues(mod1)))
color.vec[lev.vals] <- "red"

plot(hatvalues(mod1), col = color.vec,
     main = "Leverages Values in Auto Dataset",
     ylab = "Hat-values")

Under the criterion using hat-values to find leveraged values and influential points, 14 values were flagged with abnormally high leverage.

\(\hat Y = 13.04345 - 0.0545X_1 - 0.0219X_2 + 1.2006X_3\) where \(Y\) is the unit sales (in thousands) at each location (i.e. Sales), \(X_1\) is the price the company charges for car seats (i.e. Price), \(X_2\) indicates whether the store is an urban (Yes ~ 1) or rural (No ~ 0) location (i.e. Urban), and \(X_3\) indicates whether the store is in the US (Yes ~ 1) or not (No ~ 0) (i.e. US).

Note that the model can be split up into 4 separate models, depending on the context of the qualitative variables. For example, a model looking at rural stores outside of the US would be simplified to \(\hat Y = 13.04345 + 1.2006X_3\), suggesting both \(X_1\) and \(X_2\) are coded as zeros.
